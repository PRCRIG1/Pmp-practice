Formula toolkit

Quick reference + calculator
Earned Value Management (EVM)
CV = EV − AC
SV = EV − PV
CPI = EV / AC
SPI = EV / PV
EAC = BAC / CPI
ETC = EAC − AC · VAC = BAC − EAC

EV = Earned Value; AC = Actual Cost; PV = Planned Value; BAC = Budget at Completion. Positive CV is generally favourable; negative CV indicates cost overrun. SV is measured in value, not days. EAC = BAC/CPI assumes current cost efficiency continues.

PERT and three-point estimates
Expected duration = (O + 4M + P) / 6
Variance = ((P − O) / 6)²

O = optimistic, M = most likely, P = pessimistic. Apply the assumptions stated in the scenario.

Critical path and float

The critical path is the longest-duration path through the activity network and determines the earliest possible finish given network logic and constraints.

Total Float = LS − ES = LF − EF

LS = Late Start; ES = Early Start; LF = Late Finish; EF = Early Finish.

Risk responses, reserves and quality
  • Threat responses: avoid, transfer, mitigate, accept.
  • Opportunity responses: exploit, share, enhance, accept.
  • Contingency reserves typically address identified risks; management reserves address unforeseen work within the approved scope, subject to governance.
  • Control Quality verifies conformance; Validate Scope obtains acceptance of deliverables.
  • RACI: Responsible performs work; Accountable owns the outcome; Consulted provides input; Informed receives updates.
